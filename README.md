# Tradutor binário simples

Projeto foi desenvolvido como trabalho final do curso técnico.

## Sobre o projeto

A ideia é oferecer para o usuário um tradutor que possa traduzir de binario para texto ou texto para binario.

## Tecnologias usadas

- **HTML**
- **CSS**
- **JavaScript**

## Ferramentas usadas

- **VSCodium**
- **Git**
- **GitHub**
- **Ark (KDE)**

## Como mexer no projeto (meio obvio)

1. Primeiro, clone o repositório:

   ```bash
   git clone https://github.com/MostProGuy/trabalhofinaldeicc.git
   ```

2. Depois é só entrar na pasta do projeto:

   ```bash
   cd trabalhofinaldeicc
   ```

3. Depois é só abrir o arquivo `index.html` em um navegador para testar.
